# 🔌 Chrome Extension Installation

## Step 1

Download or Clone the Extension

```bash
git clone https://github.com/Varadharaj-S/automation-extension.git
```

or download ZIP from GitHub.

---

## Step 2

Open Chrome

```
chrome://extensions
```

---

## Step 3

Enable

```
Developer Mode
```

---

## Step 4

Click

```
Load Unpacked
```

---

## Step 5

Select the downloaded

```
automation-extension
```

folder.

---

## Step 6

Open LeetCode.

Login to your account.

The extension automatically captures your session securely.

---

## Step 7

Open

https://daily-submission-tracker.varadharajs2007.workers.dev/login

Login with your account.

---

## Step 8

Click

```
Connect LeetCode
```

The extension sends the session securely to

https://daily-submission-tracker-ciyc.vercel.app

---

## Step 9

Click

```
Sync
```

Your submissions will automatically appear in

- Dashboard
- Google Sheets
- Weekly Analytics
